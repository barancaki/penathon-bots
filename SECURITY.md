# Security policy

## Report a vulnerability privately

Email **[baran@penathon.co](mailto:baran@penathon.co)** with the subject `Penathon Bots security report`.

**Do not open a public GitHub issue for a vulnerability.** Send a description, affected version and operating system, reproduction steps or a minimal proof of concept, and the potential impact. Remove credentials, personal information, and real client data from all examples and attachments.

Please allow time for investigation and a fix before public disclosure. We will coordinate follow-up and disclosure with you by email. Do not access other people's data or systems to demonstrate an issue.

## Scope and updates

Security fixes target the latest release. Update before reporting and mention whether the issue also occurs on `main`, if you can safely check.

Reports about secret storage, IPC validation, folder/connection permissions, approval handling, Telegram pairing, and dependency vulnerabilities are welcome. See the [README's safety notes](README.md#privacy--safety) for documented SDK and sandbox limits; report any additional bypass privately.
